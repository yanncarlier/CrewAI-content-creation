Task: Create Social Media Text Content Plan

**Description:**
Create a 1-day text-based social media posting plan with 5 content blueprints.
Platform: Text-first networks (LinkedIn, X/Twitter threads, and Facebook).
Niche: Micro-History of Everyday Things.
Requirements: 1) 1-line "scroll-stopping" hook, 2) compelling narrative twist or surprising historical fact, 3) platform-optimized formatting (short paragraphs, bullet points, white space), 4) viral loop Call to Action (CTA) to drive replies and bookmarks.
Constraints: Written for a personal brand or solo creator voice.

**Expected Output:**
A JSON array containing a weekly schedule of 5 text post blueprints.
Schema:
{
  "posts": [
    {
      "day": "Everyday",
      "target_platform": "LinkedIn / X Thread",
      "hook_line": "Opening scroll-stopping sentence (max 15 words)",
      "body_text": "The full post copy or first 3 tweets of a thread, formatted with line breaks",
      "narrative_twist": "The surprising historical shift or fact used to pivot the story",
      "tags": ["#history", "#storytelling", "#microhistory"],
      "cta": "Question or prompt that forces a response in the comments"
    }
  ]
}
